# Myference web

The Myference marketplace and account/provider console. It uses React, TypeScript, Vite, TanStack Query, and Viem.

```bash
npm install
npm test -- --run
npm run lint
npm run build
npm run dev
```

The application renders no sample marketplace records. Models, providers, balances, requests, receipts, and Monad transactions must come from the real control-plane API or confirmed chain state.
